## 产品矩阵
### 🎬 AIGC 漫剧制作管线（5 个产品）
**解决痛点**：传统漫剧制作周期长（数周）、成本高、角色一致性难保证。

| 产品 | 定位 | 核心功能 | 效果 |
|-----|------|---------|------|
| 漫剧导演Agent | 总控中枢 | 剧本理解、任务拆解、子 Agent 调度 | 全自动管线，零人工干预 |
| 分镜规划Agent | 内容规划 | 剧本→CSV 分镜表、镜头语言生成 | 分钟级产出完整分镜 |
| 角色设计Agent | 视觉资产 | 角色特征提取、风格统一、批量出图 | 角色一致性 > 90% |
| 视频生成Agent | 内容生产 | 批量迭代生成、进度追踪、失败自愈 | 并行生成效率提升 10x |
| 后期剪辑Agent | 内容封装 | 自动合成、转场、配音、字幕 | 一键成片 |

**产品价值**：将漫剧制作周期从数周缩短至数小时，单集成本降低 80%。

### 📊 客服能力测评系统（2 个产品）

**解决痛点**：客服培训效果难量化、缺乏标准化评估体系。

| 产品 | 定位 | 核心功能 | 场景 |
|-----|------|---------|------|
| 通用版测评系统 | 标准化工具 | 答题→双维度评分→实时榜单 | 通用客服能力考核 |
| 「剧服通」定制版 | 垂直场景方案 | RAG 知识库、业务场景模拟、数据看板 | AIGC 业务客服专项测评 |

**产品价值**：建立可量化的客服能力评估标准，培训周期缩短 50%。

### 关键决策记录

| 产品 | 关键决策 | 思考过程 |
|-----|---------|---------|
| 导演Agent | 选用 Agent-Chat 而非 Workflow | 需要动态决策能力，Workflow 分支过于固定 |
| 发票审核 | 三级风控而非二值判断 | 业务场景存在模糊地带，需人工复核机制 |
| 客服测评 | 双维度评分而非单维度 | 业务要求兼顾「知识准确性」和「沟通话术」 |
| 简历质检 | A/B 双版本输出 | 让用户对比选择，提升信任度和采纳率 |
